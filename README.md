# Spotlight for Teaching

โปรแกรมทำ "ไฟฉายส่อง" บนหน้าจอระหว่างสอน บริเวณรอบเมาส์จะคมชัดและสว่าง ส่วนพื้นหลังจะเบลอ มืดลง และสีจางลง ช่วยให้ผู้เรียนมองตามจุดที่ผู้สอนกำลังอธิบาย

คู่มือนี้อธิบาย **โหมด real-time บนจอเดียว (macOS)** ซึ่งเป็นโหมดหลักสำหรับใช้สอนจริง: เปิดสไลด์ตามปกติ ขยับเมาส์แล้ววงสว่างตามไป และยังคลิกหรือเลื่อนสไลด์ได้ตามปกติ โดยไม่ต้องใช้จอที่สอง และไม่เกิดภาพซ้อน (infinite mirror)

---

## สิ่งที่ต้องมี

- macOS (ทดสอบบน MacBook จอเดียว)
- Python 3.9 ขึ้นไป
- Terminal หรือ IDE ที่ใช้รันโปรแกรม (ต้องให้สิทธิ์ตามหัวข้อด้านล่าง)

---

## ติดตั้ง (ครั้งเดียว)

```bash
cd spotlight_final
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` ติดตั้ง OpenCV, NumPy และ PyObjC (Quartz, Cocoa) ที่โหมด real-time ต้องใช้ให้ครบในคำสั่งเดียว

---

## เปิดสิทธิ์ใน macOS (ครั้งเดียว)

ไปที่ **System Settings → Privacy & Security** แล้วเปิดสิทธิ์ให้ Terminal (หรือ IDE ที่ใช้รัน เช่น VS Code, PyCharm) 2 รายการ

| สิทธิ์ | ใช้ทำอะไร |
|---|---|
| **Screen & System Audio Recording** | จับภาพหน้าจอ |
| **Input Monitoring** | ให้ปุ่มลัดทำงานแม้กำลังโฟกัสอยู่ที่แอปอื่น (เช่น Keynote, PowerPoint) |

เปิดสิทธิ์แล้ว **ปิด Terminal / IDE แล้วเปิดใหม่** ก่อนรัน ไม่อย่างนั้นสิทธิ์ยังไม่มีผล

## ทดสอบก่อนใช้งานครั้งแรก

```bash
python live_mac.py --check
```

หน้าจอจะวาบแดงสั้นๆ แล้วแสดงผล

- **`[check] ผ่าน`** → ใช้งานได้ (ภาพที่จับได้บันทึกไว้ที่ `check_capture.png` ลบทิ้งได้)
- **`[check] ไม่ผ่าน`** หรือ **`คืนค่า None`** → ดูหัวข้อ "แก้ปัญหา" ด้านล่าง

---

## ใช้งานจริงระหว่างสอน

1. เปิดสไลด์ (Keynote, PowerPoint, PDF หรือเว็บ) ให้พร้อม
2. รันใน Terminal:
   ```bash
   python main.py --source live
   ```
3. กลับไปที่สไลด์ ขยับเมาส์ วงสว่างจะตามเมาส์ คลิกหรือกดลูกศรเลื่อนสไลด์ได้ตามปกติ
4. เลิกใช้: กด `q` หรือ `ESC` (หรือ `Ctrl+C` ใน Terminal)

Terminal จะแสดง FPS ทุก 30 เฟรม ใช้ดูว่าภาพลื่นพอหรือไม่

### ปรับค่าตอนเริ่ม

| ตัวเลือก | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `--preset 1/2/3` | 2 | ความแรงของเอฟเฟกต์: 1 = อ่อน (เหมาะกับสไลด์ตัวหนังสือเยอะ), 2 = กลาง, 3 = เข้ม (เน้นจุดเดียวชัดๆ) |
| `--live-scale` | 1.0 | ย่อภาพก่อนประมวลผล (0.25–1.0) ลดลงถ้าภาพกระตุก |
| `--fps` | 30 | เพดาน FPS |

ตัวอย่าง:
```bash
python main.py --source live --preset 1 --live-scale 0.75
```

## ปุ่มลัด (ใช้ได้ขณะโฟกัสอยู่ที่สไลด์)

| ปุ่ม | หน้าที่ |
|---|---|
| `1` `2` `3` | เปลี่ยน preset อ่อน / กลาง / เข้ม |
| `+` / `-` | ขยาย / ย่อวงสว่าง |
| `[` / `]` | ขอบวงคมขึ้น / นุ่มขึ้น |
| `,` / `.` | พื้นหลังมืดขึ้น / สว่างขึ้น |
| `;` / `'` | พื้นหลังเบลอน้อยลง / มากขึ้น |
| `k` / `l` | ความคมในวงลดลง / เพิ่มขึ้น |
| `b` | เปลี่ยนรูปทรง: วงกลม → สี่เหลี่ยม → แถบแนวนอน (อ่านทีละบรรทัด) |
| `e` | เปิด/ปิดการเพิ่ม contrast และความคมในวง |
| `r` | เปิด/ปิดเส้นขอบวง |
| `o` | ซ่อน/แสดง Spotlight ชั่วคราว |
| `h` | แสดง/ซ่อนค่าปัจจุบันและวิธีใช้บนจอ |
| `s` | บันทึกภาพหน้าจอปัจจุบันเป็น `spotlight_<เวลา>.png` |
| `q` / `ESC` | ออกจากโปรแกรม |

> **ข้อควรระวัง:** ปุ่มลัดรับจากทุกแอป ถ้าต้องพิมพ์ข้อความระหว่างที่โปรแกรมทำงาน (เช่น พิมพ์ในช่องค้นหาหรือแก้สไลด์) ตัวอักษรจะไปสั่งงานด้วย โดยเฉพาะ `q` ที่จะปิดโปรแกรม ให้ปิดโปรแกรมก่อนพิมพ์ แล้วค่อยรันใหม่

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ขึ้น `ยังไม่ได้รับสิทธิ์ Screen Recording` หรือ `จับภาพหน้าจอไม่ได้` | เปิดสิทธิ์ Screen & System Audio Recording แล้วปิด-เปิด Terminal ใหม่ |
| กดปุ่มลัดแล้วไม่มีอะไรเกิดขึ้น | เปิดสิทธิ์ Input Monitoring แล้วปิด-เปิด Terminal ใหม่ |
| ภาพกระตุก FPS ต่ำ | ลองตามลำดับ: `--live-scale 0.75` → `--live-scale 0.6` → `--fps 24` → กด `3` (preset 3 เบลอพื้นหลังเบากว่า) |
| `เปิดโหมด live ไม่ได้` | ยังไม่ได้ติดตั้ง PyObjC: `pip install -r requirements.txt` ใหม่ใน venv ที่เปิดใช้อยู่ |
| `--check` ขึ้น `คืนค่า None` ทั้งที่เปิดสิทธิ์แล้ว | macOS รุ่นใหม่อาจไม่รองรับ API ที่ใช้ (ดูข้อจำกัด) ระหว่างนี้ใช้โหมด snapshot แทนได้ |
| ใช้ Keynote แบบเต็มจอแล้ว Spotlight ไม่ขึ้น | กด `o` สองครั้งเพื่อซ่อนแล้วแสดงใหม่ |

## ข้อจำกัด

- ใช้ได้เฉพาะ **macOS** และ **จอหลัก** (จอที่มีเมนูบาร์)
- จับภาพที่ความละเอียดแบบ point (เช่น 1440×900 บนจอ Retina) ตัวหนังสือในสไลด์จึงนุ่มกว่าของจริงเล็กน้อย
- ใช้ API `CGWindowListCreateImage` ซึ่ง Apple เลิกแนะนำตั้งแต่ macOS 15 ถ้าอัปเดต macOS แล้ว `--check` ไม่ผ่าน ต้องเปลี่ยนไปใช้ ScreenCaptureKit

---

## หลักการทำงาน

1. สร้างหน้าต่างเต็มจอ ไร้ขอบ ลอยเหนือทุกแอป และ **คลิกทะลุได้** ผู้สอนจึงควบคุมสไลด์ข้างใต้ได้ตามปกติ
2. จับภาพเฉพาะ **หน้าต่างที่อยู่ใต้หน้าต่างของโปรแกรม** ภาพที่จับได้จึงไม่มีผลลัพธ์ของตัวเองปนเข้ามา ภาพซ้อนจึงเกิดไม่ได้
3. ส่งภาพเข้า `SpotlightRenderer` เพื่อประมวลผล แล้ววาดผลลัพธ์กลับลงหน้าต่างในข้อ 1

การประมวลผลภาพใน `spotlight.py`:

```
out(x,y) = M(x,y) · F(x,y) + (1 − M(x,y)) · B(x,y)
```

| ส่วน | เทคนิค |
|---|---|
| **F** บริเวณโฟกัส | CLAHE บนช่อง L ของ LAB (เพิ่ม contrast), Unsharp Masking (เพิ่มความคม), เพิ่มความสว่างผ่านช่อง V ของ HSV |
| **B** พื้นหลัง | Gaussian Blur (ย่อภาพก่อนเบลอเพื่อความเร็ว), ลดความอิ่มสีและความสว่างผ่านช่อง S และ V ของ HSV |
| **M** mask | ไล่ระดับขอบด้วย smoothstep `M = 3t² − 2t³` สร้างครั้งเดียวแล้วแคชไว้ |

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `main.py` | จุดเริ่มโปรแกรม รับตัวเลือก และวนลูปของโหมดอื่นๆ |

## โหมดอื่น (สำรอง)

ใช้เมื่อโหมด live ใช้ไม่ได้ เช่นบน Windows หรือ macOS ที่ไม่รองรับ API

| คำสั่ง | ใช้เมื่อ |
|---|---|
| `python main.py --source snapshot` | ถ่ายหน้าจอค้างไว้ 1 ภาพแล้วส่องบนภาพนั้น (กด `c` เพื่อถ่ายใหม่) ใช้จอเดียวได้ทุกระบบ |
| `python main.py --source screen --monitor 1` | มี 2 จอ: จับจอที่เปิดสไลด์ แสดงผลบนอีกจอ (ดูหมายเลขจอด้วย `--list-monitors`) |
| `python main.py --source webcam` | ใช้ภาพจากกล้องเว็บแคม |
| `python main.py --source video --path clip.mp4` | ทดสอบกับไฟล์วิดีโอ |
