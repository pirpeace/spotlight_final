# โหมด real-time บนจอเดียว (macOS)

## ติดตั้ง (ครั้งเดียว)
    pip install pyobjc-framework-Quartz pyobjc-framework-Cocoa

## เปิดสิทธิ์ใน macOS (ครั้งเดียว)
System Settings > Privacy & Security
1. **Screen & System Audio Recording** — เปิดให้ Terminal (หรือ IDE ที่ใช้รัน) เพื่อจับภาพหน้าจอ
2. **Input Monitoring** — เปิดให้ตัวเดียวกัน เพื่อให้ปุ่มลัดทำงานตอนที่โฟกัสอยู่ที่แอปอื่น
แล้วปิดและเปิด Terminal ใหม่

## ขั้นตอนทดสอบ
1. ตรวจว่าวิธีไม่ให้ภาพซ้อนใช้ได้บนเครื่องคุณ:
       python live_mac.py --check
   ต้องขึ้น "ผ่าน" (หน้าจอจะวาบแดงสั้น ๆ และมีไฟล์ check_capture.png)
2. รันจริง:
       python main.py --source live
   เปิดสไลด์ไว้ แล้วขยับเมาส์ วงสว่างต้องตามเมาส์ และคลิกเลื่อนสไลด์ได้ตามปกติ

## ปุ่มลัด
เหมือน main.py เดิม เพิ่มเติม: `o` ซ่อน/แสดง Spotlight ชั่วคราว, `h` แสดงสถานะ/วิธีใช้, `q` หรือ ESC ออก (หรือ Ctrl+C)

## ถ้าภาพกระตุก
- `--live-scale 0.75` (หรือ 0.6) ลดขนาดภาพก่อนประมวลผล
- `--preset 3` เบากว่า preset 1-2
- `--fps 24` ลดเพดาน FPS

## ข้อจำกัดที่ควรรู้
- รองรับเฉพาะจอหลัก (จอที่มีเมนูบาร์)
- จับภาพที่ความละเอียดแบบ "point" (เช่น 1440x900 บน Retina) ตัวหนังสือในสไลด์จึงอาจนุ่มกว่าของจริงเล็กน้อย
- ใช้ API `CGWindowListCreateImage` ซึ่ง Apple ประกาศเลิกแนะนำตั้งแต่ macOS 15 ถ้า `--check` ไม่ผ่านหรือคืนค่า None
  บนเครื่องที่อัปเดตล่าสุด แปลว่าต้องเปลี่ยนไปใช้ ScreenCaptureKit (บอกผมพร้อมผลที่ขึ้นหน้าจอ)
